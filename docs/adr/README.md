# Architecture decision records

Every ADR number in order, one line each, with the decision in force. Read the line first and open the ADR only when you need its detail. Numbers are never reused: a gap is marked unused, and an ADR merged into another is marked with its new home.

- [0001](0001-react-native-expo-with-native-widget.md) React Native and Expo on a development build; the widget is SwiftUI over an App Group.
- 0002: superseded by 0065.
- [0003](0003-own-backend-instead-of-baas.md) Our own TypeScript backend on Postgres, not a BaaS.
- [0004](0004-native-builds-in-eas-cloud.md) Native builds run in EAS; a manual CI macOS runner builds the simulator app for Maestro.
- 0005: merged into 0041.
- [0006](0006-editions-extend-core-only-through-extension-points.md) An Edition changes the Core only through Feature Switches, Extension Points and Decor; its config names its assets (fonts, widget palette, link domain, Apple ids, notification sound); Core fonts live in the Core.
- [0007](0007-editions-live-at-head.md) Every Edition builds from `main`; per-Edition control is switches and update channels.
- 0008: merged into 0030.
- [0009](0009-editions-declare-their-content-targets.md) An Edition's content floors live in `content/targets.json`; the pack build fails on a miss.
- [0010](0010-each-edition-keeps-an-append-only-id-registry.md) `content/ids.json` lists every Entry id ever issued; ids are never reused, a Word that goes is Retired.
- [0011](0011-the-content-version-follows-the-content-checksum.md) `content/manifest.json` pairs the content version with its checksum; `--record` raises it.
- [0012](0012-definitions-come-from-goroh.md) Ukrainian Definitions and Examples come from goroh «Тлумачення», citing СУМ-20 or СУМ-11.
- [0013](0013-the-core-owns-the-user-state-schema.md) The Core owns the user-state keys, encoding, migrations and sync marks; adapters store text records by key.
- [0014](0014-editions-supply-decor-as-vector-motifs.md) Decor is vector motifs in `decor/decor.json`; the Core owns the slots and draws them.
- [0015](0015-one-entries-module-decides-which-entries-are-eligible.md) One Entries module decides eligibility and owns the table of Entry kinds; any Entry stays reachable by id.
- [0016](0016-the-feed-is-told-which-card-is-on-screen.md) The shell tells the Feed which card is on screen; the Feed owns Seen, the place, the next card and the Feed Notices.
- [0017](0017-one-entry-card-draws-every-kind-of-entry.md) One Entry card draws every kind; the Core builds the card, Round, Share Card and Entry row models; strings come from `EditionProvider`.
- [0018](0018-one-core-composition-opens-the-feed-and-the-users-words.md) One Core composition opens the Feed and the user's words, linked through named subjects; it takes the whole Edition.
- [0019](0019-a-hidden-category-is-a-category-outside-the-mix.md) A Category is hidden exactly when it is out of the Mix; other kinds of Entry are in or out as a whole.
- [0020](0020-counts-take-cldr-plural-forms-with-a-polyfill-for-hermes.md) Count strings come in CLDR plural forms, chosen with `Intl.PluralRules`, polyfilled on Hermes.
- [0021](0021-the-core-plans-notifications-and-a-port-schedules-the-whole-plan.md) The Core plans every notification; a port replaces the whole pending plan.
- [0022](0022-one-core-module-owns-the-day-change.md) One Core module owns the day change in a fixed order; the shell only reports the foreground.
- 0023: merged into 0006.
- [0024](0024-the-game-asks-about-words-in-history-and-draws-distractors-from-the-whole-pack.md) The Game asks about eligible Entries in History (15 or more), else the whole pack, and draws Distractors from every eligible Entry; Round planning alone decides a start.
- [0025](0025-the-core-turns-a-game-change-into-its-haptic-sequence.md) `createGameHaptics` in the Core turns each Game change into its haptic sequence.
- [0026](0026-the-widget-reads-a-widget-snapshot-the-core-builds.md) The Core builds the Widget Snapshot, the app writes it into the App Group, the widget only reads it.
- [0027](0027-source-folders-group-modules-by-glossary-domain.md) One folder per glossary domain, the same name in every package; folders import one way; routes import through `@/`.
- [0028](0028-maestro-runs-only-on-the-owners-command.md) Maestro runs only on the owner's command; a ticket's PR touches no flow, one visual pass per version does.
- [0029](0029-ui-components-are-tested-in-jest-with-jest-expo.md) UI components and app routes are tested in Jest with `jest-expo`; everything else in Vitest.
- [0030](0030-the-backend-is-a-factory-too.md) One backend deployment for every Edition: a server Core plus an HTTP edge, data partitioned by Edition, Sessions, limits and the client address.
- [0031](0031-the-api-only-grows-within-a-version.md) The API is one oRPC contract that only grows within `/v1`, held by a committed description.
- [0032](0032-content-updates-ship-whole-language-packs.md) A Content update is the whole Language Pack of a newer content version; a pack format rises when an older app can't read it.
- [0033](0033-the-language-pack-is-the-runtime-source-of-categories.md) The app reads Categories only from the Language Pack; Corrections have a list of Categories of their own.
- 0034: unused.
- [0035](0035-one-module-reads-an-edition-folder.md) `edition-folder.ts` is the only code that knows an Edition folder's layout; the Edition check refuses missing glyphs and release placeholders.
- [0036](0036-the-shell-opens-each-resource-once-through-one-module-and-draws-screens-over-it-open.md) The shell opens each resource once through `opening.ts`, draws every screen over it open, and hands one Shell down.
- [0037](0037-the-core-account-opens-apart-from-the-composition.md) The Core's Account opens apart from the composition and keeps the Session.
- 0038: unused.
- 0039: merged into 0064.
- [0040](0040-remote-feature-switches-only-turn-features-off.md) A remote Feature Switch only turns a feature off; every reader uses the effective value.
- [0041](0041-offline-first-sync-opaque-records-and-the-clients-change-time-wins.md) Offline-first: the backend keeps opaque records, devices exchange changes, the client's change time, cut to the server's, wins.
- 0042: merged into 0004.
- [0043](0043-knowledge-marks-and-review.md) A Known or Unknown mark schedules Review at 1, 3, 7, 30 and 90 days, then Learned (1.0: extended from 7 days); due Entries return in the Feed and the Game.
- [0044](0044-the-app-version-follows-the-release.md) The app version is the milestone the code on `main` belongs to; EAS keeps the build number.
- [0045](0045-a-correction-writes-its-stress-in-its-text.md) A stress trap writes its Stress in its text; the Correction Types and Literary Uses, which the build checks.
- [0046](0046-an-idiom-is-the-third-kind-of-entry.md) An Idiom is a kind of Entry with an Idiom Type (idiom, place name, proverb), not a Word.
- [0047](0047-one-account-per-email-whatever-the-sign-in-method.md) One Account per email; the backend verifies Google's and Apple's tokens itself.
- [0048](0048-crash-reports-go-to-sentry-with-no-personal-data.md) Crash reports go to Sentry only with a DSN from the environment and carry no personal data.
- [0049](0049-each-edition-publishes-its-legal-pages.md) An Edition's legal pages are Markdown in its folder, published on GitHub Pages behind its domain.
- 0050: merged into 0033.
- [0051](0051-synonym-row-and-tip-are-the-fourth-and-fifth-kinds-of-entry.md) A Synonym Row and a Tip are full kinds of Entry with Feed turns and Mix switches of their own; notifications stay Words.
- [0052](0052-game-modes-typed-answers-a-best-result-per-mode-and-the-daily-crossword.md) Thirteen Game Modes with their own Lives, limits and answer forms, one typed-answer comparison, a Best result per mode, the Daily Crossword.
- 0053: merged into 0027.
- [0054](0054-learning-and-habit-search-the-rarity-test-feed-notices-the-daily-limit-and-mood.md) Search, the Rarity Test, the Feed Notices, the Word of the Day archive, the Active Days calendar, the polite pause, the first week, the widget hint and Mood; the Daily Limit is retired for the Daily Goal (0066) and Mood is paused in 1.0.
- [0055](0055-motion-seasons-and-holidays-the-falling-stress-and-illustrations.md) Animations last 200–300 ms on the UI thread and fade under Reduce Motion; Decor follows the Season or Holiday (paused in 1.0); the falling Stress; Illustrations.
- [0056](0056-mistake-reports.md) «Повідомити про помилку» sends an anonymous report to `POST /v1/reports`; the owner reads and resolves them with scripts.
- [0057](0057-spotlight-and-app-intents-read-what-the-core-decides.md) The Core builds the Spotlight Snapshot; Swift only writes it; App Intents only open the app.
- [0058](0058-a-shared-collection-is-a-server-snapshot-behind-a-link.md) A Collection Link is an immutable server snapshot at `https://<linkDomain>/c/<id>`, with a web page and universal links.
- [0059](0059-react-compiler-runs-on-code-without-animation.md) The React Compiler is on; animated modules opt out with `'use no memo'`.
- [0060](0060-anonymous-community-counters.md) Community Counters are anonymous deltas aggregated per Entry; the Community Word is the week's most saved; one switch covers them and Analytics (0068).
- 0061: merged into 0006.
- [0062](0062-ota-updates-are-signed-and-ship-per-edition-channel.md) OTA updates are signed, bound to the native fingerprint, on the app's one channel from the AppConfig, published by hand.
- [0063](0063-the-backend-runs-as-one-container-on-railway-behind-the-editions-domain.md) The backend runs as one container on Railway behind the Edition's domain; migrations in the release step, one trusted proxy hop, HTTPS only.
- [0064](0064-one-backend-port-shaped-by-the-api-contract.md) The Core reaches the backend through one port, the contract's client; `answerOf` and the retry rule live in the Core; tests serve the contract in process.
- [0065](0065-one-app-with-editions-inside-and-the-ua-edition.md) One app per platform with the Editions inside, one active at a time (a switch restarts the app), the others downloaded on choice; the first is the UA Edition, id `uk`.
- [0066](0066-the-xp-log-derives-the-streak-the-active-day-freezes-and-the-break.md) An append-only XP log derives XP, Level, Active Day (≥5 XP), Streak, freezes and Break, merged by id; the Daily Goal replaces the Daily Limit (amends 0054).
- [0067](0067-onboarding-is-short-and-asks-two-questions.md) Onboarding: welcome, the first Word, two questions, the Daily Goal, the Feed; the rest comes later as Feed Notices.
- [0068](0068-analytics-go-through-one-port-and-questionnaire-counters-carry-no-id.md) Analytics go through one Core port behind the one privacy switch; questionnaire counters carry no reader id (amends 0060).
