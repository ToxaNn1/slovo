# Architecture decision records

Every ADR number in order, with a one-line summary of the decision in force. Read the summary first and open the ADR only when you need its detail. Numbers are never reused: a gap is marked unused, and an ADR merged into another is marked with its new home.

- [0001: React Native + Expo, with the widget written natively](0001-react-native-expo-with-native-widget.md). The app is React Native and Expo (TypeScript) on a development build; the home-screen widget is SwiftUI and reads what the app shares through an App Group.
- [0002: One app per language, not one app with a language switch](0002-one-app-per-language.md). Each language ships as its own Edition, a separate App Store app built from the shared Core, with UI and content in the same language.
- [0003: Own TypeScript backend instead of a BaaS](0003-own-backend-instead-of-baas.md). The backend is our own TypeScript service with its own Postgres, auth and sync, not Supabase or Firebase.
- [0004: Native builds run in EAS cloud, not locally](0004-native-builds-in-eas-cloud.md). Native binaries are built in EAS, since the laptop can't build the current SDK; a simulator build for tests may run on a CI runner (ADR 0042).
- [0005: Offline-first with last-write-wins sync](0005-offline-first-sync.md). The app reads and writes a local database and syncs in the background by last write wins per record, with tombstones; the Streak is derived from Active Days; one Account spans every Edition.
- [0006: Editions extend the Core only through switches, extension points and decor](0006-editions-extend-core-only-through-extension-points.md). An Edition changes the Core only through Feature Switches, Extension Points and Decor; it is configuration plus content and assets, and its config names the Word of the Day font, the widget palette and `linkDomain`.
- [0007: Every Edition builds from the latest Core; per-Edition control comes from switches and release channels](0007-editions-live-at-head.md). The Core is not versioned; every Edition builds from `main` and is controlled by Feature Switches and release channels.
- [0008: One backend deployment, built as a factory](0008-one-backend-deployment-built-as-a-factory.md). All Editions share one backend and one database, partitioned by Edition, built like the app with a server Core and Extension Points.
- [0009: Each Edition declares its content targets, and the pack build enforces them](0009-editions-declare-their-content-targets.md). An Edition may declare content floors in `content/targets.json`; the pack build reports every miss and exits non-zero.
- [0010: Each Edition keeps an append-only registry of the Entry ids it has issued](0010-each-edition-keeps-an-append-only-id-registry.md). Every Entry id an Edition issued is listed in `content/ids.json`; ids are never removed or reused, and a Word that goes is Retired.
- [0011: The content version follows the content checksum](0011-the-content-version-follows-the-content-checksum.md). `content/manifest.json` pairs the content version with the content checksum; the build fails when they drift, and `--record` raises the version.
- [0012: Ukrainian Definitions and Examples come from goroh «Тлумачення»](0012-definitions-come-from-goroh.md). Ukrainian Definitions and Examples come from goroh «Тлумачення», citing СУМ-20 where it covers the Lemma and СУМ-11 otherwise.
- [0013: The Core owns the user-state schema; adapters store text records by key](0013-the-core-owns-the-user-state-schema.md). The Core owns the keys, encoding, schema version and forward-only migrations of the user state; adapters only store text records by key, and the Core marks how each record syncs.
- [0014: Editions supply Decor as vector motifs; the Core draws them in its slots](0014-editions-supply-decor-as-vector-motifs.md). An Edition describes Decor as vector motifs in `decor/decor.json`; the Core owns the slots and draws them, filling any slot left out; slots 1 and 2 follow the Season or Holiday (ADR 0055).
- [0015: One Entries module decides which Entries are eligible](0015-one-entries-module-decides-which-entries-are-eligible.md). The Core's Entries module alone decides which Entries are eligible; any Entry stays reachable by id.
- [0016: The Feed is told which card is on screen and keeps the next card ready](0016-the-feed-is-told-which-card-is-on-screen.md). A shell tells the Feed only which card is on screen; the Feed owns Seen, dwell time, the reader's place and the next card, and publishes immutable cards to subscribers, Feed Notices among them.
- [0017: One Entry card draws every kind of Entry; the Edition's words and voice come from a provider](0017-one-entry-card-draws-every-kind-of-entry.md). One Entry card draws every kind of Entry; the Edition's strings and voice come from an `EditionProvider`, the Category names with the card models; the Core builds the Round models too, their form resolved, and `GameRound` draws them.
- [0018: One Core composition opens the Feed and the user's words together](0018-one-core-composition-opens-the-feed-and-the-users-words.md). One Core composition opens the Feed and the user's words over one Entries module and makes every link between them; shells subscribe and hold no rules.
- [0019: A Hidden Category is a Category outside the Mix](0019-a-hidden-category-is-a-category-outside-the-mix.md). A Category is hidden exactly when it is out of the Mix; each Category of Words or of Corrections has its own record over the Edition's default, and other kinds of Entry are in or out as a whole.
- [0020: Counts take CLDR plural forms, with a polyfill for Hermes](0020-counts-take-cldr-plural-forms-with-a-polyfill-for-hermes.md). Edition count strings come in CLDR plural forms, chosen with `Intl.PluralRules`, polyfilled on Hermes with only the Edition's locale data.
- [0021: The Core plans notifications, and a port schedules the whole plan](0021-the-core-plans-notifications-and-a-port-schedules-the-whole-plan.md). The Core plans every notification (date, time, Word, text, sound); a scheduler port replaces all pending notifications with the plan; titles come from 10 templates and the plan stops 14 days after the last open.
- [0022: One Core module owns the day change, and the shell only reports the foreground](0022-one-core-module-owns-the-day-change.md). One Core module decides a new local day began and turns the composition to it in a fixed order; the shell only reports the foreground.
- [0023: The Edition names its notification sound as one optional file](0023-the-edition-names-its-notification-sound-as-one-optional-file.md). `notificationSound` in `edition.json` optionally names a sound file in the Edition's assets; without it the plan uses the system sound.
- [0024: The Game asks about Words in History and draws Distractors from the whole pack](0024-the-game-asks-about-words-in-history-and-draws-distractors-from-the-whole-pack.md). A Game Mode asks about eligible Entries in History when at least 15 of them make a Round, otherwise the whole pack, up to 5 Rounds from Unknown or due Entries, and draws Distractors from every eligible Entry of the kind; each mode keeps its own Best result.
- [0025: The Core turns a Game change into its haptic sequence](0025-the-core-turns-a-game-change-into-its-haptic-sequence.md). `createGameHaptics` in the Core turns each Game change into its haptic sequence over an injected scheduler.
- [0026: The widget reads a Widget Snapshot the Core builds](0026-the-widget-reads-a-widget-snapshot-the-core-builds.md). The Core builds a Widget Snapshot, the app writes it as JSON into the App Group, and the widget only reads it; a new kind of Entry keeps format 1. The optional `wordOfTheDaySeenOn` draws a ✓ («Слово дня переглянуто») in every Widget Mode and size until local midnight, and each widget chooses its «Тло» (Авто, Світлий, Темний, Пергамент, Синій) from the Edition's palette, left to the system in the tinted and clear modes of iOS 18.
- [0027: Source folders group modules by glossary domain](0027-source-folders-group-modules-by-glossary-domain.md). Source folders of the Core, UI and app are named after the glossary's domains, the same set in each package; the Core barrel exports only what another workspace package or app imports, and the Core's own tests import from module files; fakes sit behind `@slovo/core/testing`. Finished by ADR 0053.
- [0028: Maestro runs only on the owner's command](0028-maestro-runs-only-on-the-owners-command.md). Maestro (any flow, the full smoke, the manual `maestro.yml`) runs only on the owner's command, normally once per spec at its end; a PR that changes a screen writes or updates its flow but does not run it.
- [0029: UI components and app routes are tested in Jest with jest-expo](0029-ui-components-are-tested-in-jest-with-jest-expo.md). Components of `packages/ui` and routes of `apps/mobile` are tested in Jest with `jest-expo`; everything else stays in Vitest.
- [0030: The backend is a factory too](0030-the-backend-is-a-factory-too.md). The backend is a server Core plus an HTTP edge, learns Editions from their configs, keeps data apart per Edition, and owns the sign-in limits and Sessions.
- [0031: The API only grows within a version](0031-the-api-only-grows-within-a-version.md). The API is one oRPC contract in `packages/contracts`; within `/v1` it only grows, held by a committed description (`pnpm describe:api`).
- [0032: Content updates ship whole Language Packs](0032-content-updates-ship-whole-language-packs.md). A Content update is the Edition's whole Language Pack of a newer content version, never a delta; a new closed-set value, Word field or kind of Entry takes a new pack format, now 9, which adds a source's short name for the cards' «Джерело:» line.
- [0033: The Language Pack is the runtime source of Categories](0033-the-language-pack-is-the-runtime-source-of-categories.md). The app reads Categories, of Words and of Corrections, only from the Language Pack; `edition.json` Categories, and the Categories whose Words must carry their Word History, are read at build time.
- 0034: unused.
- [0035: One module reads an Edition folder](0035-one-module-reads-an-edition-folder.md). `packages/language-pack/src/edition-folder.ts` is the only code that knows an Edition folder's layout; everything reads Editions through it, and the Edition check refuses a Word of the Day font missing a glyph of the alphabet, a Lemma's punctuation or the Stress mark.
- [0036: The shell opens each resource once through one module and draws every screen over it open](0036-the-shell-opens-each-resource-once-through-one-module-and-draws-screens-over-it-open.md). The shell opens each resource once through `apps/mobile/src/opening.ts` and draws every screen over it open, and its retry or fallback; every opening is a field of one Shell value that `ShellProvider` hands down and `useShell()` reads.
- [0037: The Core's Account opens apart from the composition, and requests to the backend try again by one rule](0037-the-core-account-opens-apart-and-requests-retry-by-one-rule.md). The Core's Account opens apart from the composition, and every request to the backend retries by one rule.
- 0038: unused.
- [0039: The app's API adapters are tested against the contract served in process](0039-the-apps-api-adapters-are-tested-against-the-contract-served-in-process.md). The app's API adapters are tested against the contract served in process by `serveApi`, not hand-written responses.
- [0040: Remote Feature Switches only turn features off](0040-remote-feature-switches-only-turn-features-off.md). A remote Feature Switch can only turn a feature off; every reader uses the effective value, the Edition's value and not off remotely.
- [0041: Sync exchanges opaque records and the client's change time wins](0041-sync-exchanges-opaque-records-and-the-clients-change-time-wins.md). The backend keeps opaque records; devices exchange changes, and the client's change time, cut to the server's time, decides which wins.
- [0042: A CI macOS runner builds the simulator app and runs Maestro](0042-a-ci-macos-runner-builds-the-simulator-app-and-runs-maestro.md). A manual workflow builds the simulator app on a GitHub macOS runner and runs Maestro there; release and device builds stay in EAS.
- [0043: Knowledge Marks and Review](0043-knowledge-marks-and-review.md). A Known or Unknown mark schedules Review at 1, 3 and 7 days, then Learned; due Entries return in the Feed and the Game.
- [0044: The app version follows the release](0044-the-app-version-follows-the-release.md). The app version in `app.config.ts` is the milestone the code on `main` belongs to.
- [0045: A Correction writes its Stress in its text](0045-a-correction-writes-its-stress-in-its-text.md). A stress-trap Correction writes its Stress as a combining acute mark in its text, with no position field. It lists the Correction Types, `paronym` among them, and lets a Correction carry up to three public-domain Literary Uses that the build checks.
- [0046: An Idiom is the third kind of Entry](0046-an-idiom-is-the-third-kind-of-entry.md). An Idiom is a third kind of Entry with its own id prefix, Idiom Type (idiom, place name or proverb), Definitions and Examples, not a Word; Synonym Row and Tip follow (ADR 0051).
- [0047: One Account per email, whatever the Sign-in method](0047-one-account-per-email-whatever-the-sign-in-method.md). An email has one Account, and every Sign-in method (Sign-in code, Google) reaches it; the backend verifies Google's token itself.
- [0048: Crash reports go to Sentry, with no personal data](0048-crash-reports-go-to-sentry-with-no-personal-data.md). Crash reports go to Sentry only with a DSN from the environment, and carry no personal data.
- [0049: Each Edition publishes its legal pages](0049-each-edition-publishes-its-legal-pages.md). An Edition's privacy policy and terms live in `editions/<id>/legal/` as Markdown in its language and are published per Edition.
- [0050: Corrections have their own Categories](0050-corrections-have-their-own-categories.md). An Edition lists Categories for Corrections apart from the Words'; every Correction names one, the build refuses an unknown one, and the pack carries the list.
- [0051: Synonym Row and Tip are the fourth and fifth kinds of Entry](0051-synonym-row-and-tip-are-the-fourth-and-fifth-kinds-of-entry.md). A Synonym Row (a dominant, a meaning and 5–12 members with Stress) and a Tip (a rule with its standard form and its own Game question) are full Entries with ids `r_`/`t_`, pack format 5, Feed turns every 9th and 11th card and Mix switches of their own; notifications stay Words only.
- [0052: Game Modes of 0.8.12](0052-game-modes-of-0-8-12.md). Eleven new Game Modes with their own Lives, Round limits, time limits and answer forms (pick, vowel tap, pairs, chips, typed text), one Core comparison of typed answers, a Best result per mode (`game.best.<mode id>`), a Feature Switch per mode, and the Daily Crossword, generated by the pack build 400 days ahead and kept on the device; Words gain `origin`, pack format 6.
- [0053: Every domain has one folder name in every package](0053-every-domain-has-one-folder-name-in-every-package.md). A domain has a folder of the same name in every package where it appears, even with one module; `mix/` holds the Mix and Hidden Entries, the Core's crossword joins `game/`, the app gains `shell/` and `diagnostics/`, routes import `src` through `@/`, and domain folders import each other one way (`domain-folders-import-one-way`, an error).
- [0054: Learning and habit in 0.8.13](0054-learning-and-habit-in-0-8-13.md). Search over every non-Retired, non-Hidden Entry, the Rarity Test that sets the Rarity Floor, Feed Notices (Weekly Recap, Yesterday, first week, Daily Limit) outside the Feed's turns, a synced Word of the Day archive, Knowledge Marks with a time, the Active Days calendar, the polite pause and 10 notification templates, the widget hint, and Mood on Words with pack format 7; a Feature Switch for each.
- [0055: Feel of 0.8.14](0055-feel-of-0-8-14.md). Animations last 200–300 ms, follow gestures with springs, run on the UI thread and become an opacity fade under Reduce Motion; slots 1 and 2 of Decor follow the meteorological Season of the local date or the Edition's Holiday, which wins, behind the synced «Сезонний декор»; the Word Lemma's Stress falls in 300 ms on Word cards in the Feed and the Entry screen; a Word may name a bundled PNG Illustration in `illustration`, which the build checks, pack format 8.
- [0056: Mistake Reports](0056-mistake-reports.md). «Повідомити про помилку» on cards of all five kinds sends `POST /v1/reports` (Edition, Entry id, type `typo`/`stress`/`definition`/`other`, a comment of at most 500 characters that `other` needs, app version, content version; 202) with no Account, no device id and no stored IP, 10 a day per IP; a device queue of 20 sends by the one retry rule; the owner reads and resolves (deletes) reports with backend scripts.
- [0057: Spotlight and App Intents read what the Core decides](0057-spotlight-and-app-intents-read-what-the-core-decides.md). The Core builds a Spotlight Snapshot (each Entry in Favorites, any Collection or the Word of the Day archive once, each Collection as «Колекція · {n} слів»; Hidden and Retired Entries left out; empty with `spotlight` off) that a local Swift module writes into CoreSpotlight, replacing the index, on background and on every change, a tap opening the existing Entry and Collection routes; the App Intents «Слово дня» and «Відкрити гру» with App Shortcuts only open the app on the Word of the Day card or the Game, or its start with `appIntents` off.
- [0058: A shared Collection is a server snapshot behind a link](0058-a-shared-collection-is-a-server-snapshot-behind-a-link.md). «Поділитися посиланням» stores an immutable, never-expiring snapshot (`POST /v1/collection-links` {edition, name of 1–60 characters, 1–200 Entry ids} → a 10-character id and `https://<linkDomain>/c/<id>`; `GET /v1/collection-links/{id}`) with no Account, no device id and no stored IP, 20 a day per IP, apart from Sync; `linkDomain` comes from the Edition, the app-site-association file takes the Team ID from the environment; «Додати собі» copies it as the reader's own Collection («(2)» on a name clash, missing Entries skipped and counted, Hidden kept); the owner deletes a link with `collection-links delete`; `collectionLinks` can be switched off remotely.
- [0059: The React Compiler runs on code without animation](0059-react-compiler-runs-on-code-without-animation.md). The app config turns the React Compiler on; every module with Reanimated, Worklets or gesture-handler code opts out with `'use no memo'`, the compiler's lint rules are errors, and hand memoisation stays until the opted-out modules are checked one by one.
- [0060: Anonymous Community Counters](0060-anonymous-community-counters.md). A channel apart from Sync with no Account, no device id and no stored IP: the device sends deltas of known, unknown and saved (`POST /v1/counters/events`, 500 a day per IP) only for what it counted itself after the update, never Game answers; the server keeps aggregates per Entry and Favorites adds per ISO week; reads are cached 24 hours; `GET /v1/community/week` gives the Community Word; «Ділитися анонімною статистикою» is device-only and on by default.
