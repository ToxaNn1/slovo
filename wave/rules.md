# Wave rules for every implementer (spec #1949 «Сервіси»)

- Follow `CLAUDE.md` and `docs/agents/ticket-brief.md` (skip its cloud/status-commit parts: you report in your final reply). Read the spec `/tmp/claude-0/1949.md` and your ticket `/tmp/claude-0/<n>.md`; do not call GitHub.
- Work only in your worktree. Test first (red, then green) through the spec's seams. Inject time and randomness.
- Commit with `/tmp/claude-0/gc.sh -m "<msg>"` only (never plain git commit, never type an email). Conventional Commits, types feat/fix/docs/chore/test/refactor, scopes = workspace folder names (`admin`, `backend`, `contracts`, `server-core`…). No Co-Authored-By, no AI mention, never the word «claude» in messages. No push, no `&`/`nohup`, no EAS.
- `export DATABASE_URL=postgres://slovo:slovo@localhost:5432/slovo` before backend tests. A backend test failing only with Postgres «permission denied to terminate process» is flake: rerun once.
- Output through `tail -30` / `--output-logs=errors-only`. Checks for affected packages only: `pnpm turbo run lint typecheck test --filter=<pkg> --output-logs=errors-only`; never full `pnpm test`.
- Generated files (migrations `meta/`, `v1.openapi.json`, `pnpm-lock.yaml`, `routeTree.gen.ts`) only through their scripts (`pnpm --filter backend db:generate`, `pnpm --filter contracts describe-api`, the router generator); never hand-edit or print them. No new dependencies (no lockfile change) unless unavoidable: then say so.
- Reserved: ADR 0164–0166, migrations: at most one per ticket, generated by drizzle. Use only the number your brief gives.
- Cost-first: before calling any outside API (Railway, Neon, GitHub, Cloudflare, NBU, Sentry, PostHog), write requests × bytes × frequency against its limits in your report. Vault values and real keys never appear in logs, tests, fixtures or the Action log; tests use fake keys.
- No Ukrainian outside UI strings and Edition content. Use glossary terms (Service, Service entry, Vault).
- Before DONE: `git merge feat/1949-services` (integration tip) into your branch, rerun affected checks, commit.
- Final reply ≤ 10 lines, first line `DONE #<n>` / `STUCK #<n>` / `FAILED #<n>`: branch, last commit, checks run, owner questions with your safe default, the handbook page «Сервіси» change in one Ukrainian sentence, cost notes. Longer notes go to `/tmp/claude-0/report-<n>.md`.
