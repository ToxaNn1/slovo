## Top 5

1. **R3** `apps/backend/src/content/content-queue.ts:145`: lock order inverted against `write`, so a content write and a batch review/rollback can deadlock in Postgres. Breaks the admin content flow under normal concurrent use.
2. **R4** `apps/backend/src/recordings/recordings.ts:184`: one bad Word makes the generator throw before failures are marked, so the same Words are retried forever and the Recording job (and later Editions) never moves on.
3. **R7** `apps/admin/src/switches/kill-tab.tsx:24`: while Editions are loading, «Вимкнути зараз» sends no Edition id, which kills the feature in every Edition. One early click has production-wide effect.
4. **R1** `packages/core/src/game/chips-form.ts:139`: `judge` lets one tile be used twice, so wrong answers pass and earn XP. Core game rule broken for every Edition.
5. **R6** `packages/ui/src/entries/WordCard.tsx:276`: the Definition is invisible to the whole-lines cut, so the «Суть» tab can show nothing or a sliced line: the main content of a Word card.
