## Findings

### a2.1: PLAUSIBLE, medium. A Quick Question's answer card remounts and is announced again on every parent re-render
- **Where:** `packages/ui/src/game/GameRound.tsx:327-330` together with `packages/ui/src/game/AnswerSheet.tsx:35-37` and `AnswerCard.tsx:32-34`.
- **Defect:** `QuickQuestionRound` builds `explained` as a new object literal on every render. `AnswerSheet` treats any `answer !== shown.answer` as a new answer: it calls `setShown` during render, increases `count` and remounts `AnswerCard` with `key={shown.count}`. `AnswerCard` then runs `announceForAccessibility` again on mount. In the Game, `round.answer` comes from the Core with a stable identity. In the Feed it does not.
- **Consequence:** while the sheet is open, any re-render of the Feed page (a subscription tick, a pager state change, a Theme change) makes VoiceOver read «Влучно! …» again. The card also remounts and loses its Button's press state.
- **Fix:** keep the explained answer stable. Memoise it on `[explaining, answered, round]`, or store it in state when the option is picked. Alternatively, compare `chosen`/`correct` in `AnswerSheet` instead of identity.

### a2.2: CONFIRMED (traced), medium. The offline plate is never announced by VoiceOver on iOS
- **Where:** `packages/ui/src/primitives/OfflinePlate.tsx:144-151`.
- **Defect:** the plate relies on `accessibilityRole="alert"` and `accessibilityLiveRegion="polite"`. `accessibilityLiveRegion` works on Android only. On iOS a view that appears with the role `alert` is not read out by itself. No `AccessibilityInfo.announceForAccessibility` is called, though `BadgeToast.tsx:47` and `AnswerBanner` do call it for the same kind of transient message. The test (`OfflinePlate.test.tsx:100`) checks only the role.
- **Consequence:** a VoiceOver reader whose action failed for lack of network hears nothing, and the plate hides after 3.2 s.
- **Fix:** announce `message` on mount (for example, in the `ready` effect). Add a test that spies on `announceForAccessibility`.

### a2.3: CONFIRMED (traced), low. «ФІНІШ» flies in fully under the system Reduce Motion
- **Where:** `packages/ui/src/game/FlyIn.tsx:159-176`, with `providers/useReduceMotion.ts:12-40`.
- **Defect:** `useReduceMotion()` returns `false` on the first render of every mount until `isReduceMotionEnabled()` resolves. `FlyIn` starts `withTiming` with `ReduceMotion.Never` in that first effect. When Reduce Motion later turns out to be true, the effect returns early and does not cancel or jump the running animation. The hook's own doc says that a mount animation must use `useReduceMotionKnown`, as `OfflinePlate` does. `AnswerBanner.tsx:83-94` has the same race, but it recovers: it jumps to 0 once the value is known, after a partial slide.
- **Consequence:** a reader who turned on the system Reduce Motion, with «Менше руху» off in the app, sees the full 480 pt fly-in on every Game end poster. This breaks `docs/react-native.md` («Respect `useReduceMotion()` for every animation»).
- **Fix:** in `FlyIn`, wait for `useReduceMotionKnown() !== undefined` and set `flown.value = 1` when it is true. Do the same in `AnswerBanner`.

### a2.4: CONFIRMED (traced), low. Crossword grid cells shrink below the minimum touch target and have no slop
- **Where:** `packages/ui/src/game/CrossingGrid.tsx:82-92, 182-195`. The tokens are in `tokens/game.ts:196-197` (`cell: 54`, `minCell: 30`).
- **Defect:** on a short screen the cell side can go down to 30 pt. `PressedTile` gets no `hitSlop`, so the tap area becomes 30 × 30, below `minTouchTarget` (44).
- **Consequence:** on small phones, or with a large grid, cells are hard to hit. This breaks the guide's accessibility rule.
- **Fix:** give each cell a `hitSlop` of half the gap, or raise `minCell` towards 44 and let the room scroll.

### a2.5: CONFIRMED (traced), low. Ukrainian headings on the Games hub carry no `voice`
- **Where:** `packages/ui/src/game/GameModeCard.tsx:145-171` (`GamesTitle`, `GameModeGroupTitle`); `CrosswordSolvedPoster.tsx` (the `shareNoSpoiler` header); `GameEndPoster.tsx:94-99` (the «НОВИЙ РЕКОРД!» stamp).
- **Defect:** these Texts in the Edition's language don't spread `voice` from `useEdition()`, which the guide requires (`docs/react-native.md`, Accessibility).
- **Consequence:** with a system language other than Ukrainian, VoiceOver reads these headings with the wrong voice.
- **Fix:** spread `{...voice}` on each of them.

### a2.6: PLAUSIBLE, low. A Quick Question that is reset to unanswered on the same instance never plays its answer motion again
- **Where:** `packages/ui/src/game/PickRound.tsx:229-238`.
- **Defect:** `shownAnswered` is set to true once and never goes back to false when `answer` returns to `undefined`. Compare `useAnswerMotion.ts:105-109`, which does reset. Inside a Game the options are keyed by the Round, so only the Quick Question instance (no key) is affected, if the Feed ever clears `answered` on a mounted card.
- **Consequence:** the next answer shows its final look at once, with no pop or fade.
- **Fix:** reset `shownAnswered.current = false` when `look === 'rest'`, as `useAnswerMotion` does.
